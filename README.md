# Java Backend Yolculuğu

**Hedef:** Junior Java Backend Developer olarak işe girmek (öncelik remote).
**Başlangıç:** 30 Eylül 2026
**Tempo:** Haftada ~40 saat (6 gün × 6 saat + Pazar hafif tekrar)

## Dosyalar

| Dosya | Ne işe yarar |
|---|---|
| `PLAN.md` | 16 haftalık yol haritası, fazlar, projeler |
| `ILERLEME.md` | Günlük log + haftalık kontrol listesi (her gün sonunda doldurulur) |
| `CV-NOTLARI.md` | Mevcut CV'nin dürüst analizi ve yeniden yazım planı |
| `hafta-XX/gun-XX/` | O günün ders notu (`DERS.md`) ve senin yazdığın kodlar |

## Çalışma Kuralları (anlaşmamız)

1. **Kodu sen yazarsın.** Claude anlatır, soru sorar, ipucu verir, review eder. Senin yerine çözüm yazmaz.
2. **AI ile kod üretmek yok.** Takıldığında önce 20 dk kendin uğraş → sonra dokümana bak → sonra ipucu iste.
3. **Kağıt-kalem:** Her dersin sonunda "Kağıda Yaz" kutusu var. Sadece onu yazarsın (5-10 satır). Sayfalarca not yok.
4. **Her gün commit.** Gün sonunda kodunu GitHub'a push'la. Yeşil kareler hem disiplin hem CV.
5. **Her oturum hesap sorma ile başlar:** "Dün ne yaptın, ne takıldı, kağıda ne yazdın?"
6. Bir günü kaçırırsan plan kaymaz, telafi edilir. İki gün üst üste kaçırmak yok.
